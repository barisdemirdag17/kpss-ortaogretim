# KPSS Ortaöğretim Sınav Rehberi

KPSS Ortaöğretim sınavına hazırlanan adaylara yönelik kapsamlı rehber websitesi.

## 📋 Projede Neler Var?

### 🏠 Ana Sayfa
- KPSS Ortaöğretim'in tanıtımı
- Temel istatistikler (120 soru, 130 dakika)
- Hızlı erişim butonları

### 📋 Konu Dağılımı
- **Genel Yetenek Testi** (60 soru)
  - Türkçe: 30 soru (Paragraf 15, Sözel Mantık 4, diğerleri 11)
  - Matematik: 27 soru (Problemler 8, Matematiksel İlişki 6, vb.)
  - Geometri: 3 soru
- **Genel Kültür Testi** (60 soru)
  - Tarih: 27 soru (Osmanlı 9, Atatürk İnkılap 9, vb.)
  - Coğrafya: 18 soru (Ekonomik 8, Fiziki 4, vb.)
  - Vatandaşlık: 9 soru
  - Güncel Bilgiler: 6 soru

### ❓ Soru Türleri
- Türkçe paragraf soruları (detaylı)
- Matematik problemleri ve sayısal mantık
- Tarih, coğrafya ve vatandaşlık soru türleri

### 📅 Stratejik Çalışma Planı
- 3 aşamalı çalışma planı (Temel Atıf → Güçlendirme → Final)
- Önemli stratejik tavsiyeler

### 📊 Puan Hesaplama
- Doğru/yanlış cevaplara göre tahmini puan hesaplama
- Animasyonlu sonuç gösterimi

## 🛠️ Teknolojiler

- **HTML5** - Sayfa yapısı
- **CSS3** - Tasarım (CSS değişkenleri, flexbox, grid, animasyonlar)
- **Vanilla JavaScript** - Etkileşimli özellikler
- **Google Fonts** - Inter & Playfair Display fontları
- **Tailwind CSS** - Kullanılmamış, tam özelleştirilmiş CSS

## 🚀 Nasıl Açılır?

`index.html` dosyasını bir web tarayıcısında açın:

```bash
# Windows
start index.html

# veya dosyayı çift tıklayın
```
